# Auto Upgrade Session #1 — Shotlist

## Ziel
Ersten echten Auto-Upgrade-Clip drehen: kurz, verständlich, loopfähig.

## Clip-Titel
Auto Upgrade Session #1 — Bluetooth verbindet

## Video-Text
```text
POV: Einer verbindet sich im Auto
```

## Caption
```text
Auto Upgrade ist kein Song, das ist ein Zustand 🚗🔥
```

## Pinned Comment
```text
Soll Auto Upgrade droppen? 🚗🔥
```

## Länge
Ziel: 8–12 Sekunden

## Ablauf

### Shot 1 — Stille
**Dauer:** 0–2 Sek  
**Bild:** Alle sitzen ruhig im Auto.  
**Vibe:** müde, gelangweilt, Abend fast vorbei.  
**Text Overlay:** POV: Einer verbindet sich im Auto

### Shot 2 — Auslöser
**Dauer:** 2–4 Sek  
**Bild:** Eine Person nimmt Handy / tippt auf Bluetooth.  
**Dialog:** „Mach mal Project Zero an.“

### Shot 3 — Blickkontakt
**Dauer:** 4–5 Sek  
**Bild:** Kurzer Blick zwischen allen.  
**Sound:** 1 kurzer Moment Stille / Spannung.

### Shot 4 — Drop
**Dauer:** ab 5 Sek  
**Sound:** AUTO UPGRADE — BASS MACHT DRUCK  
**Bild:** Fenster runter, Licht, Bewegung, shaky Cam.

### Shot 5 — Eskalation
**Dauer:** 5–11 Sek  
**Bild:** Alle gehen mit, Kopf nickt, Bass-Vibe, Lichtwechsel.  
**Regel:** Nicht zu sauber filmen. Raw wirkt besser.

### Shot 6 — Loop-Ende
**Dauer:** letzte Sekunde  
**Dialog:** „Mach nochmal an.“  
**Ziel:** Clip startet logisch wieder von vorne.

## Pflicht-Elemente

- [ ] Auto / Innenraum sichtbar
- [ ] Bluetooth- oder Handy-Moment
- [ ] kurzer Blickkontakt
- [ ] Drop bei Sekunde 5 oder früher
- [ ] Fenster runter oder Lichtwechsel
- [ ] shaky Cam
- [ ] Loop-Ende

## Varianten

### Variante A — Clean
Normaler Clip mit klarer Story.

### Variante B — Aggressiv
Drop früher setzen, mehr Energie, mehr Bewegung.

### Variante C — Meme
Übertriebene Reaktion, fast absurd.
