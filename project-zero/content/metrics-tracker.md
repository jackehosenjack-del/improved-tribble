# Project Zero Metrics Tracker

## Ziel
Nach jedem Clip schnell erkennen, welche Hooks, Szenen und Formate skalierbar sind.

## Kernmetriken

| Metrik | Bedeutung | Ziel |
|---|---|---|
| Views | Reichweite | frühes Signal |
| Watchtime | hält der Clip? | wichtigster Qualitätswert |
| Completion Rate | wird bis Ende geschaut? | Loop prüfen |
| Replays | schauen Leute mehrfach? | starkes Viral-Signal |
| Kommentare | triggert der Clip Reaktion? | Community Loop |
| Shares | ist der Clip teilenswert? | Wachstum |
| Saves | wird der Clip gespeichert? | Langzeitwert |
| Profilklicks | macht der Clip neugierig? | Branding |
| Sound-Nutzung | nutzen andere den Sound? | Trend-Signal |
| Link-Klicks | Traffic zu SoundCloud | Conversion |

## Bewertung

### Grünes Signal
Ein Clip bekommt schnell:

- überdurchschnittliche Watchtime
- viele Kommentare
- mehrere Shares
- sichtbare Profilklicks

Aktion:

- gleiche Szene nochmal drehen
- gleiche Hook behalten
- Perspektive ändern
- 2–3 Varianten nachlegen

### Gelbes Signal
Clip bekommt Views, aber wenig Kommentare oder Shares.

Aktion:

- Caption ändern
- Pinned Comment stärker machen
- kürzer schneiden
- Drop früher setzen

### Rotes Signal
Clip stirbt schnell und hat schwache Watchtime.

Aktion:

- Hook austauschen
- Setup kürzen
- Szene wechseln
- Drop innerhalb der ersten 3–5 Sekunden testen

## Hook-Test Matrix

| Hook-Typ | Beispiel | Ziel |
|---|---|---|
| Direkt | AUTO UPGRADE — BASS MACHT DRUCK | sofortige Wiedererkennung |
| POV | POV: Einer verbindet sich im Auto | schnelle Szene |
| Frage | Wer macht auch immer lauter? | Kommentare |
| Challenge | Mach dein POV dazu | Sound-Nutzung |
| Loop | Mach nochmal an | Replays |

## Skalierungsregel

Wenn ein Clip klar besser läuft als der Rest:

```text
Nicht neu erfinden. Gewinner kopieren, Kontext ändern.
```
