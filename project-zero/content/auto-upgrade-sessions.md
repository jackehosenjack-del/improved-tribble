# Auto Upgrade Sessions

## Serienformat
Auto Upgrade Sessions

## Feste Video-Formel

**0–2 Sek:**  
Langweilige Situation / Stille

**2–4 Sek:**  
Jemand sagt: „Mach mal Project Zero an.“

**4–5 Sek:**  
Kurzer Blickkontakt / Bluetooth verbindet

**5 Sek:**  
Drop: „AUTO UPGRADE — BASS MACHT DRUCK“

**5–12 Sek:**  
Eskalation, Licht, shaky Cam, Fenster runter

**Ende:**  
„Mach nochmal an.“  
Damit loopt der Clip sauber zurück.
